## Quick Cutscene Skip

###### Tired of waiting for slow automatic dialogue? 🫤 Let the automatic F key presses handle it for you. 😏 Presses the F key once every second.

1. [Download](https://www.autohotkey.com/) the application, then right-click the script and run [fButton.ahk](app-image://download) as administrator.
2. Enter the game and press `F8` at the point where you want to skip a cutscene. (`F8` toggles the feature on and off.) However, be aware that some cutscenes may result in an **infinite loop**, so avoid using it around loop-triggering sections.
