A desktop tool for **Mod management and game solutions**.

ModNest provides a more convenient way to manage your games and Mods.

---

## ✨ Features

### 📦 Mod Management

- File-based Mods only
- Import Mods
- Enable and disable Mods
- Categorize Mods
- Support for multiple games

---

### 🎮 Custom Game Management

In addition to preset games, ModNest also supports:

- Add custom games
- Set custom Mod directories
- Independent configuration for each game
- Switch between multiple games

---

### 🔧 Game Solutions

Currently includes:

1. **Genshin Impact 10612-4001 Error Fix**
2. **Automatic F Key Cutscene Skip ⚡**
